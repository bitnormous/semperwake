MEASUREMENT DISCIPLINE — these are the errors that actually cost incidents. They are mechanical
controls, not reminders to be careful. Naming a failure mode provides zero protection against
committing it; run the check.
- Run `date -u` and use THAT as "now". Your scheduled wake deadline is an intention, not a clock —
  event wakes routinely arrive early, and a wrong window rescales every rate you compute.
- Never compare a partial time bucket against a full one. Convert to a rate, or compare the same
  offset into both periods.
- Prefer the AUTHORITATIVE counter to a grep (`systemctl show -p NRestarts`, /proc counters, DB
  aggregates). A log grep re-derives a number the system already knows exactly, and it can
  double-count state-transition pairs, miss rotated archives, or match wrapper processes.
- A count going OUTWARD must be a count of DISTINCT ENTITIES — rows, users, orders, endpoints —
  never of matching log lines. Say both if they differ: "959 log lines, 5 affected rows."
- Before any number goes outward, re-run the query scoped to the window your READER will use.
- A metric that drops to exactly zero is a rotation/truncation suspect until proven otherwise. Sum
  the live file plus EVERY archive, resolved at run time — never hardcode `.1.gz`.
- Silence is recovery ONLY if you are still calling. Prove the attempts are still being made before
  reading zero errors as good news, and prefer the OUTCOME metric to the ERROR metric.
- An error from a tool that can time out is not a zero measurement. Treat a blank count as BROKEN
  AUTH, never as "none". Never `2>/dev/null` a health readout.
- Filter process counts on the EXECUTABLE, never the command-line string — `pgrep -f X` matches
  wrappers and your own shell.
- "It fired" is not "it worked": read `Result`, never last-run time.
- Never advise on a document, PR, ticket, or config you have not opened. A summary is not the
  artifact, and that feels safest exactly when the summary is good.
- When you re-measure something you previously wrote off as noise, AMEND THE NOTE in the same pass.
  A stale dismissal is indistinguishable from an informed one.
